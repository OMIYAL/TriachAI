# 🚀 TriArchV5 — v2026.8.11.1013 (August 11, 2026)

## ✨ New

**🔎 Auto-detect symbols on takeoff plans**
When counting devices on a plan PDF, you can now drag a box around one example symbol and let the system find and place every matching symbol on that page automatically — instead of clicking each one by hand. You'll see a busy indicator while it searches, a clear message if nothing matches, and a chance to confirm, redraw, or cancel before anything is placed. The device count log now also breaks down totals into how many were placed manually versus auto-detected, so you can see at a glance how much of the count was automated.

**🏗️ Foundation for full 3D building models**
Projects now have the underlying support to store detailed building models — floors, spaces, and structural elements — using industry-standard BIM data, with comments that can be attached to specific parts of a building. This lays the groundwork for richer 3D views and floor plans in upcoming releases.

## 💪 Improvements

**🙋 See who submitted a service request**
The Service Requests list now shows who submitted each request right under its tracking number, alongside when it was last updated — no more guessing or opening the request just to check.

**🧾 Payment requests show which service request they belong to**
The payment requests table now includes a clickable tracking number linking back to the originating service request, plus a "Purpose" column (intake fee, activity fee, or credit pack) so it's clear what each payment is for at a glance.

## 🐞 Fixes

**🚫 Deactivated services can no longer receive new requests**
Previously, a service request could still be created or submitted against a service that had been deactivated. This is now blocked with a clear message explaining that the service is deactivated, and pointing you to reactivate it in Service Catalog settings or choose a different service instead.
